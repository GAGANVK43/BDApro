📌 Problem Statement & Objective
Why large-scale entertainment catalog processing requires modern Big Data architecture

Modern streaming platforms like Netflix and Amazon Prime manage massive entertainment catalogs containing hundreds of thousands of titles produced across global film markets. Analyzing this data involves unnesting multi-valued dimensions (such as co-directors, comma-separated genres, and multi-country co-productions) over millions of records.

Project Objective: Build an end-to-end distributed Big Data pipeline that utilizes Hadoop HDFS for scalable distributed storage, Apache Hive for SQL-on-Hadoop aggregations, MongoDB Atlas for flexible document and statistics persistence, and Flask + Chart.js for deploying a high-performance web dashboard to Vercel.

🎓 Expected Faculty Viva Voce Questions & Answers
Key technical explanations for academic project review

Q1: Why use Hadoop HDFS when data can be stored directly in MongoDB?

Answer: HDFS acts as the central distributed Data Lake designed for high-throughput batch writes and long-term immutable raw storage (OLAP). MongoDB acts as the operational database (OLTP) holding processed, indexed documents and pre-calculated statistics for fast user-facing web queries.

Q2: How does Hive handle multi-valued comma-separated fields like genres?

Answer: In hive/genre_analysis.hql, we use Hive's LATERAL VIEW explode(split(listed_in, ',')) syntax. This flattens the comma-separated strings into individual records, allowing standard SQL GROUP BY and COUNT() operations.

Q3: How does the architecture work between local processing and Vercel cloud deployment?

Answer: Hadoop and Hive run in the data engineering environment to clean and aggregate the large dataset. The resulting processed records and collections are ingested into MongoDB Atlas. The Flask application is deployed to Vercel, querying MongoDB Atlas directly via PyMongo without needing a live Hadoop node on the web edge.

Q4: What data cleaning operations are performed by Python?

Answer: python/data_cleaning.py eliminates duplicate entries by title and year, imputes null directors and casts with 'Unknown', normalizes maturity ratings to official standards (TV-MA, PG-13), parses durations into numeric values and units, and extracts primary countries and genres for fast indexing.
