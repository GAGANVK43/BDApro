🏗️ End-to-End Big Data Architecture & Flow
How raw entertainment datasets flow from ingestion to live visualization
1

Raw Dataset Ingestion

The platform ingests raw Netflix and movie CSV files with multi-genre lists, multi-country strings, missing directors, and raw durations.

2

Python Data Cleansing & Deduplication (python/data_cleaning.py)

Removes duplicate titles, standardizes maturity ratings to official MPAA standards, extracts numeric durations into integers (minutes for movies, seasons for TV shows), and normalizes comma-separated fields.

3

Hadoop HDFS Distributed Storage (/netflix-analytics/cleaned)

Cleaned dataset is uploaded to Hadoop HDFS, creating a scalable, fault-tolerant distributed data lake across nodes.

4

Apache Hive SQL-on-Hadoop Analytics (hive/*.hql)

Hive creates external and partitioned ORC tables, executing large-scale aggregations using LATERAL VIEW explode(split(listed_in, ',')) and window growth functions.

5

MongoDB Atlas NoSQL Store (python/load_mongodb.py)

Aggregated analytical results and indexed movie documents with native array fields (genres: [], country: []) are persisted into MongoDB Atlas.

6

Flask REST API & Interactive UI (app.py + JavaScript)

Flask REST endpoints serve JSON to modern Chart.js charts, giving users responsive filtering, live status monitoring, and metadata exploration.
